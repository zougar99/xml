# werlist99 — Blogger Hub v6.1

الملف الرئيسي: **`werlist99-hub-template.xml`** — قالب Blogger كامل بواجهة عربية RTL وإنجليزية LTR، يجمع بين مدونة تقنية وصفحة مشاريع GitHub.

## أهم التحسينات

- تصميم عصري ومتجاوب مع الهاتف واللوحة وسطح المكتب، بما في ذلك الشاشات الصغيرة حتى 320px والشاشات الواسعة.
- حركات ظهور متدرجة أثناء التمرير، دخول Hero، تفاعل الأزرار، وتأثير 3D خفيف لبطاقة الكود على الأجهزة ذات المؤشر الدقيق.
- Animated counters لإحصائيات GitHub وSkeleton loading للمشاريع وأحدث المقالات والمقالات المشابهة.
- انتقالات سلسة للقائمة والبحث وشريط التنقل، مع تعطيل الحركات غير الضرورية عند تفعيل `prefers-reduced-motion`.
- وضع داكن/فاتح يتبع إعداد الجهاز أول مرة، مع حفظ اختيار المستخدم.
- تبديل كامل للغة العربية/الإنجليزية وحفظ اللغة والاتجاه.
- صفحة رئيسية بهوية جديدة، تصنيفات، وبطاقات مقالات واضحة.
- صفحة مقال محسّنة: وقت القراءة، فهرس تفاعلي، تكبير الخط، الطباعة، نسخ الرابط، مشاركة اجتماعية، ومقالات مشابهة.
- أزرار نسخ لأكواد البرمجة مع بديل للمتصفحات القديمة.
- صفحة مشاريع GitHub: إحصائيات، بحث، تصفية حسب لغة البرمجة، ترتيب، cache، وحالات خطأ وإعادة المحاولة.
- أحدث المقالات من Blogger Feed مع الصور والتواريخ.
- بحث في نافذة accessible تدعم `Esc` و`Tab` ولوحة المفاتيح.
- SEO: canonical، Open Graph، Twitter Cards، RSS، WebSite/Person Schema وBlogPosting/ItemList Schema.
- تحسينات الوصولية: رابط تخطي للمحتوى، focus واضح، ARIA، تباين مناسب، واحترام `prefers-reduced-motion`.
- لا يعتمد على jQuery أو أي JavaScript framework.

## طريقة التركيب في Blogger

1. خذ نسخة احتياطية من القالب الحالي: **Blogger → Theme → Customize → Backup**.
2. افتح **Theme → Edit HTML**.
3. استبدل كامل المحتوى بمحتوى `werlist99-hub-template.xml`، ثم احفظ.
4. راجع الصفحة الرئيسية، مقالاً، وصفحة المشاريع على الهاتف والحاسوب.

> إذا كان عندك محتوى مهم داخل HTML القالب القديم، انسخه قبل الاستبدال. تغيير القالب لا يحذف المقالات أو الصفحات.

## الصفحات المطلوبة

أنشئ هذه الصفحات من **Pages** إذا لم تكن موجودة، مع الحفاظ على الروابط:

| الصفحة | الرابط |
|---|---|
| المشاريع | `/p/projects.html` |
| من أنا | `/p/about.html` |
| اتصل بنا | `/p/contact.html` |
| سياسة الخصوصية | `/p/privacy-policy.html` |
| إخلاء المسؤولية | `/p/disclaimer.html` |

صفحة `projects.html` يمكن أن تبقى فارغة أو تحتوي على مقدمة؛ القالب يعرض المشاريع تلقائياً فوق محتواها.

## التصنيفات المستخدمة

روابط الواجهة جاهزة لهذه التصنيفات. استعملها كما هي في مقالات Blogger أو عدّل الروابط والنصوص في XML حسب تصنيفاتك:

- `Troubleshooting`
- `Tech Guides`
- `Software & Tools`
- `News & Updates`
- `Productivity Tips`

كما توجد اقتراحات بحث لـ `Windows` و`Python`.

## الإعدادات السريعة

في آخر ملف XML داخل JavaScript:

```js
var GH_USER = 'zougar99';
var GH_CACHE_HOURS = 6;
var GH_MAX_REPOS = 12;
var BLOG_URL = 'https://werlist99.blogspot.com';
```

- غيّر `GH_USER` إذا تغيّر حساب GitHub.
- غيّر `BLOG_URL` إلى رابط مدونتك النهائي، خصوصاً عند استعمال domain خاص.
- حدّث روابط الشبكات الاجتماعية، الصورة الرمزية، والنصوص التعريفية عند الحاجة.
- بيانات GitHub العامة تُحمّل من متصفح الزائر وقد تتأثر بحدود GitHub API؛ القالب يستعمل cache لمدة 6 ساعات ونسخة مخزنة عند تعذر الاتصال.

## ملاحظات

- تم حذف نموذج النشرة البريدية التجريبي الذي كان يعرض رسالة نجاح دون تسجيل البريد. بدلاً منه توجد متابعة فعلية عبر RSS وGitHub. يمكن إضافة Mailchimp/Buttondown لاحقاً برابط خدمة حقيقي.
- التعليقات تستعمل نظام Blogger threaded comments المدمج.
- الترجمة تغيّر نصوص الواجهة؛ عناوين ومحتوى المقالات ووصف مستودعات GitHub يبقى كما نشره صاحب المحتوى.

## التحقق التقني

تم التحقق من سلامة XML ومن syntax الخاص بـ JavaScript. لا يمكن للتحقق المحلي أن يحاكي جميع بيانات Blogger؛ لذلك يُنصح بتجربة القالب أولاً على مدونة اختبارية أو بعد أخذ نسخة احتياطية.
